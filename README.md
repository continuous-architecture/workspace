# Workspace Continuous Architecture

Bienvenue dans l'espace de travail de la communauté [Continuous Architecture](https://continuous-architecture.org).

Cet espace permet de travailler ensemble sur des notes de réflexion, des brouillons d'articles, des retours d'expérience, des comptes rendus et des propositions de pratiques. Tout membre peut lancer un sujet ou contribuer à un projet existant.

## Comment participer ?

Vous souhaitez proposer une idée, créer un document ou améliorer un texte ? Suivez le **[guide de contribution](CONTRIBUTING.md)**. Il accompagne les débutants, sans connaissance de Git, avec l'aide d'un assistant comme Codex, Claude Code ou Copilot, éventuellement dans VS Code.

## Ressources utiles

- [Projets en cours](projets/) : consultez les sujets existants avant d'en proposer un nouveau.
- [Modèle de fiche projet](modeles/fiche-projet.md) : présentez un sujet et ses prochaines étapes.
- [Modèle de compte rendu](modeles/compte-rendu.md) : consignez les échanges et les décisions confirmées.

**Cet espace et les contributions sont publics.** Ne publiez aucune information confidentielle ni coordonnée privée. Ne citez une personne qu'avec son accord.
